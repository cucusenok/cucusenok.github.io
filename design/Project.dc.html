WHAT IT IS

Platform

Fourteen services, each in its own repository: a Go core API, chat and comments; TypeScript auth, CRDT collab backend and markdown↔Yjs converter; Python agent, RAG, documentation generator and MCP server. NATS JetStream is the event bus; Postgres, Weaviate and Redis hold state; a Helm chart deploys the whole set on any domain.

Editor and sync

Real-time collaborative editing on Yjs CRDT transported over NATS, with bidirectional GitHub sync through a GitHub App: import, pull on webhook, export, page history.

Agents

A LangGraph agent with intent routing and per-user LLM quota metering answers over a RAG index built from tree-sitter chunks and BGE-M3 embeddings. An MCP server with 36 tools, secured by OAuth 2.1, exposes the same capabilities to Claude connectors.
